# Subcon Website

Official marketing website for Subcon Pty Ltd, a residential concrete slab company servicing Western Melbourne, Northern Melbourne and the Ballarat region.

## Live site

https://somilror200.github.io/Subcon/

## Website

The site presents Subcon's residential concrete services, company background, builder relationships, project gallery and direct contact details.

### Core services shown

- Piers pouring
- Base preparation
- Steel reinforcement
- Slab pouring and finishing
- Excavation and supporting site operations
- Project consulting

## Build

- Semantic HTML5
- Responsive CSS
- Vanilla JavaScript
- GitHub Pages
- Existing Subcon project photography and company assets

The current version is a custom rebuild of the original generated site, with a shared responsive design system and no framework or build step required.
